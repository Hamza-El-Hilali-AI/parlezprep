# ParlezPrep

ParlezPrep is a French learning and exam-preparation app focused on CECRL progression from A1 to C2, with adaptive AI-style exercises and mock exam preparation for the TCF and TEF Canadian exams.

## Features

- Adaptive exercise generator by level and skill
- Progression across A1 to C2
- Skill coverage: listening, reading, speaking, writing, grammar and vocabulary
- Mock exam library for exam preparation
- Structured 7-day study plan
- Professional, responsive interface

## Run locally

Open the project in a browser directly, or serve it locally with Python:

```bash
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

## Project status

This is a front-end MVP designed to be extended with a real AI backend or API later.
